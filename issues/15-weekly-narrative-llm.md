# 15 — Weekly narrative summary via LLM Edge Function

**Type:** AFK
**Source:** Study Tracker v1 PRD

## What to build

The `WeeklyNarrative` module. A 2–3 sentence weekly summary appears automatically on the weekly progress screen each week, generated by calling the `LLMProxy` Supabase Edge Function (which wraps OpenAI GPT-4o-mini). The Edge Function holds the API key; nothing third-party leaks into the mobile binary.

The LLM is given **structured progress facts only** (from `ProgressEngine`) — never raw session data. The model **verbalizes** facts; it does not reason, infer, or recommend. Notes from any exceptional sessions in the past week are included in the structured input so the summary can acknowledge context — e.g., "you noted you were sick this week."

A button on the weekly view generates a fresh summary on demand (useful before a re-plan or to share with a study group). If the network call fails, the rest of the weekly view still renders; the summary section shows a graceful unavailable state with a retry affordance.

**Brand rule:** the summary surface must not be labeled as "AI-powered" or decorated with sparkles, robot icons, or chat-bubble framing. The intelligence is visible in the quality of the writing, not in what the surface calls itself.

## Acceptance criteria

- [ ] On the weekly progress screen, a 2–3 sentence summary appears automatically once per week
- [ ] The summary is generated by calling the `LLMProxy` Edge Function — no direct API call from the mobile app
- [ ] The Edge Function holds the OpenAI API key; the mobile binary contains no third-party API key (verified by repo grep + binary inspection)
- [ ] Inputs to the LLM call are **only** structured progress facts plus any exceptional-session notes from the past week — never raw session rows
- [ ] When the user has noted exceptional context (e.g., a sickness note), the summary acknowledges it
- [ ] A button on the weekly view triggers fresh on-demand generation
- [ ] If the network call fails, the rest of the weekly view renders unaffected; the summary section shows a graceful "unavailable — retry" state
- [ ] The summary surface has no AI-branding — no sparkles, robot icons, "AI says" framing, or chat-bubble UI
- [ ] Tests cover prompt construction (snapshot/golden tests) and end-to-end with a stubbed LLM (length bounds, week reference, no empty output)
- [ ] Tests do **not** assert specific LLM output text — that would be testing the model, not the code
